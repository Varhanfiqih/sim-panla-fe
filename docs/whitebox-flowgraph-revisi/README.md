# Flow Graph White Box Testing

Folder ini berisi beberapa flow graph perwakilan untuk bagian White Box Testing Bab 5. File ini tidak dimasukkan langsung ke laporan, sehingga dapat dipilih terlebih dahulu sesuai kebutuhan revisi.

## Daftar Flow Graph

1. Iterasi 1: `iterasi-1-flowgraph-login-web-panel.png`
   - Mewakili pengujian login web panel dan validasi role pengguna.

2. Iterasi 2: `iterasi-2-flowgraph-kelola-jadwal-pelajaran.png`
   - Mewakili pengujian validasi input jadwal dan pengecekan bentrok jadwal.

3. Iterasi 3: `iterasi-3-flowgraph-presensi-kehadiran-guru.png`
   - Mewakili pengujian check-in guru, termasuk validasi alasan saat tidak hadir.

4. Iterasi 4: `iterasi-4-flowgraph-pengajuan-izin-siswa.png`
   - Mewakili pengujian pengajuan izin siswa oleh wali kelas.

5. Iterasi 5: `iterasi-5-flowgraph-verifikasi-izin-siswa.png`
   - Mewakili pengujian verifikasi izin siswa oleh Guru BK.

## Catatan Penulisan

Flow graph ini dapat diletakkan setelah narasi pengujian white box pada masing-masing iterasi. Karena tidak semua fitur perlu dibuat flow graph, lima diagram ini cukup digunakan sebagai sampel perwakilan alur logika yang memiliki percabangan.
